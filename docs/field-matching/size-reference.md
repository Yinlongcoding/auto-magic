# AM 服装尺码映射参考表（调研版）

核查日期：2026-09-22。状态：**人工审核参考资料，尚未成为 AM 的运行时映射规则**。

本表面向从 1688 采集到 `XS / S / M / L / XL / XXL` 等字母尺码、需要填写 Ozon 俄罗斯尺码的场景。表内俄码是**指定品牌公开尺码表的示例**，不是中国尺码、国际尺码或 Ozon 的统一换算标准。仅有字母标签而没有商品尺码表、适用人群和服装类型时，不能据此裁定目标俄码。

## AM 审核时如何使用

1. 逐个 SKU 保留采集到的原始尺码文本；先确认该文本表示**服装尺码**，而非商品长宽高、包装尺寸或其他参数。
2. 查原商品或供应商的尺码表，记录其适用人群、服装类型、测量部位与单位。此处的品牌示例仅供对照，不能替代原商品证据。
3. 有可核验的商品尺码依据时，给出俄码候选及来源，交用户确认；没有依据、出现多个候选或仅有 `S/M/L` 文本时，保持 `conversion_required` / `ambiguous`，不把表中数字作为已确认结果。
4. 用户确认后，再按当前 Ozon 类目和类型的属性及字典校验可填值。表中的 `44–46` 等范围保持原样作为参考，不能自行取中间值、首值或拆成多个 SKU 值。

本表不覆盖童装、鞋、内衣、牛仔裤 `W/L`、`均码`、身高号型或供应商自定义码。这些需要各自的商品尺码依据。即使同一品牌，尺码体系也可能不同：Nike 官方女上装常规版 `M` 的胸围为 `90–97 cm`，亚洲版 `M` 为 `85–89.5 cm`，因此不应以字母本身推断身体围度。[Nike 常规版](https://www.nike.com/bg/size-fit/womens-tops-alpha) · [Nike 亚洲版](https://www.nike.com/hu/en/size-fit/womens-tops-asian-alpha)

仓库现有的 [源到目标字段合同](source-target-contract.md)将尺码换算列为 `conversion_required`，并要求外部规则、字典或人工确认；本参考表不修改该合同，也不绑定任何 Ozon 属性或字典值。
