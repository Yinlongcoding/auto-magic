# Ozon 本地测试数据

`ozon-category-tree.test.json` 是用户于 2026-08-31 提供的中文版 Ozon 品类树响应快照，仅用于验证本地品类选择和动态 Schema 流程。

- 数据规模：26 个顶级目录、568 个品类节点、7,365 个商品类型。
- 桌面端只展示包含商品类型的 542 个可选品类。
- 当前快照中的品类和商品类型名称为中文；它与此前英文快照的全部品类 ID 和“品类＋类型 ID”组合完全一致。
- 文件不包含 `Client-Id`、`Api-Key` 或其他账户凭证。
- 正式版本应由 Ozon 类目树接口更新并记录获取时间；不要把此快照视为长期有效的生产目录。
