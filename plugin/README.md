# Auto Magic 1688 Chrome DOM Demo

当前开发版本：`v0.1.6`

> 开发约定：凡修改 `plugin` 内的运行逻辑或界面，必须递增 `manifest.json` 版本号，并在交付说明中明确写出新版本。插件弹窗右上角会显示当前实际加载版本。

第一阶段验证扩展。它会在用户当前 Chrome 中：

1. 优先查找并复用当前窗口已有的1688搜索结果页；没有时才创建1688首页标签页。
2. 使用 `chrome.debugger` 附加标签页。
3. 读取 `#alisearch-input` 的当前文字并与目标关键词比较。
4. 关键词一致时跳过输入和 Enter；不一致时替换文字并模拟键盘按下 Enter。
5. 需要搜索时，追踪1688通过 `target="_blank"` 创建的结果标签页，同时兼容当前页跳转。
6. 进入结果页后不进行首次滚动，直接返回页面顶部并填写最低采购价。
7. 使用 CDP 真实鼠标事件点击最高采购价输入框，再填写最高采购价，使隐藏的价格筛选“确定”按钮显示。
8. 填写最高价后持续保持该输入框焦点；通过当前价格值锁定同一表单，查找父级属于 `.price-filter-define`、文字为“确定”的可见按钮。按钮按下时阻止默认失焦行为，再用真实鼠标事件完成点击并等待列表重新加载。
   如果当前URL参数和表单值都已是目标价格区间，则跳过重复点击和重复等待。
9. 默认选择“销量优先”；选择“价格优先”时仍按 `.sw-dpl-orderby-asc` 和 `bottom-active` 的既有DOM规则处理。发生点击时等待列表再次重新加载。
10. 排序后的列表加载完成后返回顶部，并完整滚动加载最终列表。
11. 每次滚轮向下滚动600px、间隔250ms，直至页面底部。
12. 到达底部后不额外等待，立即读取商品DOM。
13. 数据获取完成后直接将页面跳转到顶部。
14. JSON同时输出筛选排序、筛选后滚动、原始卡片数及有效/重复/无效链接计数。
15. 1688自有域名返回的HTTP商品链接会安全升级为HTTPS；其他非HTTPS链接仍会被拒绝。
16. 将商品详情地址、展示图片、纯文字名称和价格输出为JSON。
17. 完成或失败后解除调试器。
18. 列表完成后默认选择第2条商品，在Offscreen Document中隐藏获取并解析详情HTML。
19. 弹窗展示受节点数和深度限制的结构化DOM快照，完整HTML以 `.dom.html.txt` 自动导出到下载目录。

插件同时支持弹窗直接验证和桌面端 Native Messaging 搜索请求；不会关闭用户原有标签页。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `plugin`。
5. 将扩展固定到工具栏。

## 验证

1. 点击扩展图标。
2. 保留默认关键词“连衣裙”。
3. 点击“开始验证”。
4. Chrome应复用当前窗口已有的1688结果页；没有结果页时才创建1688页面，并显示“Auto Magic 1688 DOM Demo 正在调试此浏览器”。
5. 任务结束后，扩展徽标显示商品数量；失败时显示 `!`。
6. 再次打开扩展，查看或复制JSON。
7. 查看“第2条详情DOM结构”，并可通过“显示文件”定位自动导出的原始HTML文本。

## 当前限制

- 仅允许访问 `*.1688.com`。
- 同一时间只允许一个任务。
- 最多提取60条商品。
- 详情DOM调试默认只处理列表第2条，原始HTML最大5MB；结构快照最多2000个节点、12层。
- 详情页使用后台 `fetch()` 获取服务器HTML，不执行页面JavaScript；动态渲染节点可能不在快照中。
- 不处理登录、验证码或访问限制。
- 商品集合选择器为 `.search-offer-item`。
- 价格筛选表单通过 `.price-filter-form` 定位；最低价和最高价同时结合 placeholder 与 `.price-filter-end` 区分。`.form-submit` 只作为焦点状态的优先线索，最终依据当前输入值、父级 `.price-filter-define` 和按钮文字“确定”锁定同一表单，避免误点页面中另外两个同名按钮。
- 1688的价格“确定”按钮依赖最低价或最高价输入框焦点显示；点击时会阻止 `mousedown` 的默认失焦动作，使后续 `mouseup/click` 仍命中该按钮。
- 点击确认前不再将按钮滚动到页面中央，避免1688页面的平滑滚动造成坐标与实际元素短暂错位；最高价输入框仅在超出视口时进行即时的最小距离滚动。
- 筛选完成后以URL中的 `priceStart`、`priceEnd` 为最终生效依据；列表刷新和输入框值只作为过程诊断，避免“列表刷新了但价格条件未生效”的假阳性。
- 销量排序优先按可见文字“销量”定位，并以 `.sm-sort-item` 集合索引1兜底。
- 名称通过 `.title-text` 的 `textContent` 提取，因此只保留包含子标签文字在内的纯文本，不包含HTML标签。
- CSS选择器来自2026年8月26日实际页面DOM，1688改版后需要更新 `lib/config.js`。
